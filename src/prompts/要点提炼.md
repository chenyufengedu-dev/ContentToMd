## 整理方式：要点提炼

目标：删去冗余表达，让读者快速看清核心观点和具体做法；不能为了简短删掉改变结论的条件、否定、转折或例外。

参考结构（原文里没有的部分直接省略，禁止编造内容来填满结构）：
- 礼仪和为人处世类：核心观点 / 具体做法 / 示范话术（保留原话）/ 例外情况和场合
- 品牌类：背景 / 出圈原因 / 具体案例 / 可借鉴的做法与适用条件
- 金融类：核心观点 / 条件与限定 / 关键数字 / 例子 / 风险提示
- 其他内容：按内容自己组织

硬性要求：
- 原文里的数字、条件、限定说法必须保留，不能改动；结论和它的前提、限制、例外一起保留，不能只留下结论
- 内容讲的主角（品牌名、人名、产品名）必须出现在正文里；不确定写法时照原文写并加【?】，不能因为不确定就省掉
- “但是”“不够”“只有……才”“除非”等表达可能承载关键判断，不是可以直接删掉的铺垫。例如“光有 A 不够，还要 B，否则 C”，必须同时保留 A 的不足、B 的要求和 C 的后果；可压缩措辞，不能变成只介绍 A 或 B 的做法
- 描述具体做法的细节（造型、动作、画面、步骤、数字）一条都不能省，这些就是案例的精华
- 示范话术保留原话；具体做法和例子保留原意与细节。正文纠错按下面的规则执行，直接引用按“原文金句”的规则执行
- 删掉不承载观点的铺垫、自我引用（“我经常说”“我做自媒体发现”）和互动话（“有遇到过吧”“分享给大家”）；个人经历本身是例子时保留，承接上下文的限制和判断不能当铺垫删掉
- 不加“作者认为”“作者的回答是”这类转述，直接写观点和做法
- 不添加原文没有的观点、数据和例子；原文没有具体做法时，不要自己补
- 正文转述中的语音识别错误：上下文能确定的才直接改；不能仅因另一种成语、名言或说法更常见，就认定原文识别错了。靠猜的写成“猜测的词【?原文：原来的词】”；猜不出的保留原样并加【?】
- 不加原文没有的引导语或评价标签（比如“作者观点：”“自问：”“值得注意的是”）；除末尾摘录外，同一内容不在两节里重复
- 原文金句：只从材料中选取可核对的连续原句，放在 body 最后的“### 原文金句”中，通常 2～5 句；不足时少选，没有合适原句时省略该节。只允许补标点、调整空白和添加【?】标记，不能换字纠错、拼接不同句子或把转述当原话。疑似错词保留并标【?】，或另选一句；正文中的纠错授权不适用于直接引用

如果材料是图片（比如会议幻灯片、讲座照片、信息图）：从图中的文字和画面提炼要点，论点、数据、结论都要保留；读不清的地方标【?】，不猜；“原文金句”只从图中能清楚读出的连续原句里摘，没有可核对原句时省略。image_captions 每张图一句说明。

返回 JSON 前对照材料检查两件事，并在当前结果中修正，不输出检查过程：
- 每个会改变结论的否定、转折、条件和例外，在正文中都有对应表达；不是仅保留相关关键词
- 每条直接引用都能在材料中找到连续原句；与正文中的纠错、归纳或转述没有混用
