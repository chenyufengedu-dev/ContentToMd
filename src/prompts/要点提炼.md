## 整理方式：要点提炼

目标：提炼精华，让读者一眼看到“核心观点是什么、具体怎么做”，方便以后快速回看。

参考结构（原文里没有的部分直接省略，禁止编造内容来填满结构）：
- 礼仪和为人处世类：核心观点 / 具体做法 / 示范话术（保留原话）/ 例外情况和场合
- 品牌类：背景 / 出圈原因 / 具体案例 / 可借鉴的做法
- 金融类：核心观点 / 条件与限定 / 关键数字 / 例子 / 风险提示
- 其他内容：按内容自己组织

硬性要求：
- 原文里的数字、条件、限定说法必须保留，不能改动
- 内容讲的主角（品牌名、人名、产品名）必须出现在正文里；不确定写法时照原文写并加【?】，不能因为不确定就省掉
- 承上启下的判断句（比如“光有 A 不够，还要 B”）是观点的一部分，不能省
- 描述具体做法的细节（造型、动作、画面、步骤、数字）一条都不能省，这些就是案例的精华
- 示范话术、具体做法和例子保留原话（只修正识别错字和补标点）
- 删掉讲者的铺垫、个人经历、自我引用（“我经常说”“我做自媒体发现”）和互动话（“有遇到过吧”“分享给大家”），除非它本身就是例子
- 不加“作者认为”“作者的回答是”这类转述，直接写观点和做法
- 不添加原文没有的观点、数据和例子；原文没有具体做法时，不要自己补
- 改正语音识别错误时分两种：
  - 有把握的（上下文能确定是哪个词）：直接改
  - 靠猜的：写成“猜测的词【?原文：原来的词】”；原文明显不通、又猜不出来的：保留原样并加【?】
- 不加原文没有的引导语或评价标签（比如“作者观点：”“自问：”“值得注意的是”）；同一内容只出现一次，不在两节里重复
- body 最后必须有一节“### 原文金句”，原样摘录 2～5 句原文（只允许修正识别错字和补标点；正文里加了【?】的词，在金句里也要保留【?】）


如果材料是图片（比如会议幻灯片、讲座照片、信息图）：从图中的文字和画面提炼要点，论点、数据、结论都要保留；读不清的地方标【?】，不猜；“原文金句”从图中的文字里摘。image_captions 每张图一句说明。
