# Windows 图标用途

| 资源 | 用途 |
|---|---|
| icon.ico | 安装程序、EXE及默认桌面快捷方式：白底、主题色#5B5BD6标记 |
| icon.png、32x32.png、128x128.png、128x128@2x.png | 同一带底板资源的预览及打包尺寸 |
| window.png、window.ico | 透明白色备选资源，当前不被运行代码引用 |

唯一矢量源：assets/app-icon.svg。白底内部标志已整体等比放大13%并居中，路径及内部比例不变。透明备选版删除背景、改为白色，并把描边加厚至原来的1.5倍，改善小尺寸显示。桌面版直接使用源文件。
页面标志src/assets/app-mark.svg及书写动画不参与生成。

重新生成：在项目根目录运行 `python scripts/generate_icons.py`。脚本使用Python标准库和项目本地Tauri CLI，无须Pillow或新增依赖。
ICO含16、20、24、30、32、36、40、48、64、128、256像素；PNG母图512像素；窗口内嵌PNG128像素。

当前运行窗口直接复用128x128.png桌面图标（白底、主题色标记），由main.rs在窗口显示前set_icon，不随任务栏背景换色。透明版保留作备选，未被应用自动引用。
Windows固定但未运行的入口可能仍使用快捷方式/EXE图标。本项目为NSIS安装方式，未改MSIX；未新增托盘功能。既有安装程序/快捷方式不会因源码修改自动更新，需后续打包安装；Windows缓存可能仍显示旧图标。
